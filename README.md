# Hi, I'm Omri Hirsch

I build web experiences and explore natural language processing and concurrent systems. Here are selected projects I've worked on, with links to the code and a live demo.

## Selected projects

### [Villa Azurea: bilingual property website](https://github.com/OmriHrsch/Azurea-Real-Estate)

A single-page property website with an English/French interface, a photo gallery, and property information. Deployed on Vercel, with photos and video served through Vercel Blob.

**Stack:** Next.js, React, TypeScript, Tailwind CSS, Vercel Blob.

[View the live website](https://azurea-real-estate.vercel.app/) · [Explore the code](https://github.com/OmriHrsch/Azurea-Real-Estate)

### [Hebrew NLP: comparing language across eras](https://github.com/Snirbou/NLP-Project)

A team research project exploring whether Modern Hebrew is syntactically closer to Biblical or Mishnaic Hebrew.

- A text-processing pipeline using DictaBERT for morphological and syntactic analysis.
- Linguistic feature extraction, corpus comparisons, and machine learning classifiers.
- LLM style-transfer experiments and visualizations of the results.

**Stack:** Python, pandas, scikit-learn, PyTorch, Hugging Face Transformers.

[Explore the project](https://github.com/Snirbou/NLP-Project) · [Code and experiment guide](https://github.com/Snirbou/NLP-Project/blob/main/REPO_STRUCTURE.md)

### [Robot vacuum simulation and message bus](https://github.com/tomimran/vacummCleaner)

A Java coursework project exploring concurrent services and asynchronous messaging through a robot sensor simulation.

- A message bus with event and broadcast subscriptions, service queues, and futures.
- Separate services for camera, LiDAR, pose, and simulation timing.
- JSON configuration and sample sensor inputs.

**Stack:** Java, Maven, Java concurrency utilities, Gson.  
**Status:** Academic prototype; the public version includes unfinished components.

[Explore the project](https://github.com/tomimran/vacummCleaner) · [Message bus implementation](https://github.com/tomimran/vacummCleaner/blob/master/src/main/java/bgu/spl/mics/MessageBusImpl.java)
